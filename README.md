# Authors Be Bold

Official BOLD Writer project website at <https://authorsbebold.github.io/>. The application source, Issues, Discussions, and contribution guide are in [jorgenandrewjohnson-jpg/BOLDWriter](https://github.com/jorgenandrewjohnson-jpg/BOLDWriter).

This static site has no framework, tracker, or paid service. It mirrors the project website source in the BOLDWriter repository. The 3D book image is a native renderer output from a disposable synthetic manuscript, not an interactive GUI screenshot. Source and image provenance are recorded in [assets/README.md](assets/README.md).

Please propose site improvements through BOLDWriter Issues or pull requests; keep artwork and manuscript fixtures redistribution-safe.
